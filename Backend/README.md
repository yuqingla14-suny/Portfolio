# 作品集內容管理後台

## 啟動

在專案根目錄執行：

```sh
node Backend/server.mjs
```

然後開啟 <http://127.0.0.1:4173/Backend/>。第一次進入時建立管理帳號；帳號需為 3–40 個英數字元，密碼至少 12 個字元。後台不需要安裝額外套件。

## 可管理內容

- 關於我：人物標籤、個人標籤、內文、近期分享一句話。
- 精選作品：影片、照片、平面設計、繪畫；中英文標題、媒介、內文、影片連結與多張圖片。
- 專案作品：現有專案和新增專案的中英文標題、標籤、年份、介紹與多張圖片。多張圖片會在案例頁顯示輪播。
- 文章：標題、副標題、日期、分類、摘要、內文與封面圖片。

內容儲存在 `Backend/data/site-content.json`，上傳圖片存在 `images/uploads/`。請在本機使用後台；服務只監聽 `127.0.0.1`，不會直接暴露到外部網路。圖片限制為 JPG、PNG、WEBP、GIF，單張上限 15MB。

GitHub Pages 只能提供靜態檔案，無法執行登入與寫入 API。更新完成後，網站內容和上傳圖片已寫入專案檔案；要發布到 GitHub Pages，仍需將變更提交並推送到網站儲存庫。若要在外部主機直接登入編輯，需將 Node 服務部署到可執行伺服器程式的平台並啟用 HTTPS。
